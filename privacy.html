Privacy

Swag County is a static landing page. There is almost nothing about you to collect.

Effective 2026-05-24

What this site collects

Nothing, directly. Swag County (the home page at swagcounty.com) is a single static HTML page. There are no forms, no signups, no analytics, no advertising, no cookies, and no JavaScript that talks to a backend.

Server logs

Our web server keeps standard access logs (IP address, user agent, request path, HTTP status) for debugging and abuse prevention. These logs are retained for a limited period and are not used to build a profile of you or shared with third parties.

Cookies and storage

This page sets no cookies, writes nothing to localStorage or sessionStorage, and registers no service worker.

Sub-projects

Some links from this page go to interactive sub-projects (for example, shuffleify). Sub-projects that handle user data publish their own privacy policy on their own page. Read the policy for the sub-project you are using — it will be more specific than this one.

Third parties

Swag County does not embed third-party scripts, analytics, ads, or tracking pixels. The page uses social-preview metadata (Open Graph and Twitter Card) so links shared on other platforms render with an image and title; those platforms fetch the image directly from this site and we receive no information back about who shared it.

Your rights

Since this site does not store personal data about you server-side, there is nothing for us to export, correct, or delete on request. If you are in the EU, UK, or California and want to exercise a data right anyway (right of access, erasure, etc.), email us at the address below and we will confirm in writing that we hold no records about you.

Contact

Privacy questions, data requests, or anything else: nerds@swagcounty.com.

Changes to this policy

If we change how Swag County handles data, this page will be updated and the effective date at the top will move forward. The change history is visible in the public Git history of the repository.
